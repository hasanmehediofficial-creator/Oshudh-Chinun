# ওষুধ চিনুন — প্রাথমিক Android সংস্করণ

বাংলা UI-সহ একটি প্রাথমিক Android অ্যাপের কাঠামো। Android Studio ছাড়া GitHub Actions দিয়ে debug APK build করার workflow আছে।

## এখন যা আছে
- বাংলা হোম স্ক্রিন ও সার্চ ইনপুট
- নমুনা ব্র্যান্ড/জেনেরিক কার্ড
- প্যাকেটের ছবি নির্বাচন করার বোতাম (OCR এখনো যুক্ত নয়)
- ডার্ক মোড
- তথ্যসূত্র ও যাচাইয়ের তারিখ দেখানোর জায়গা
- GitHub Actions থেকে APK build artifact

## গুরুত্বপূর্ণ সীমাবদ্ধতা
- প্রদর্শিত Napa, Seclo ও ORS রেকর্ডগুলো UI demonstration-এর জন্য; এগুলো পূর্ণ বা বর্তমান সরকারি ডেটাবেস নয়।
- প্রকৃত মূল্য, DGDA registration ID, লাইসেন্সপ্রাপ্ত ডেটাসেট, অনলাইন আপডেট ও অফলাইন ডেটাবেস এখনো সংযুক্ত হয়নি।
- ছবি নির্বাচন চালু, কিন্তু OCR ফলাফল থেকে ওষুধ শনাক্তকরণ এখনো বাস্তবায়িত নয়।
- অ্যাপ চিকিৎসা পরামর্শ বা ডোজ নির্ধারণের বিকল্প নয়।

## APK তৈরি
GitHub-এর Actions ট্যাব খুলে Build Android APK workflow রান শেষ হওয়া পর্যন্ত অপেক্ষা করুন। সফল হলে run-এর Artifacts অংশ থেকে Oshudh-Chinun-debug-apk ডাউনলোড করুন। এটি debug APK; release-signed APK নয়।
