# ওষুধ চিনুন — Android অ্যাপ

বাংলা UI-সহ Android অ্যাপ; GitHub Actions দিয়ে APK তৈরি হয়।

## বর্তমানে যুক্ত ফিচার
- বাংলা সার্চ UI; নমুনা রেকর্ডে ব্র্যান্ড, জেনেরিক, শক্তি/ফর্ম, প্রস্তুতকারক, মূল্য-অবস্থা, উৎস ও যাচাইয়ের তারিখ দেখানো।
- প্যাকেটের ছবি নির্বাচন এবং ডিভাইসে ML Kit OCR দিয়ে লেখা পড়ার চেষ্টা।
- ডার্ক মোড।
- বুকমার্ক করে সংরক্ষিত তালিকা; SharedPreferences-এ ডিভাইসে সংরক্ষিত থাকে।
- সরকারি DGDA ওষুধের তালিকা এবং DGHS নিবন্ধিত ওষুধের রেজিস্ট্রি খোলার লিংক।
- ইন্টারনেট পারমিশন যুক্ত।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
- Napa, Seclo ও ORS এখনো কেবল UI নমুনা। এগুলোকে পূর্ণ/যাচাইকৃত ডেটাবেস হিসেবে দেখানো হচ্ছে না।
- DGDA-এর অনলাইন তালিকা অ্যাপের মধ্যে স্বয়ংক্রিয়ভাবে ডাউনলোড/সিঙ্ক হয় না; এই সংস্করণে সরকারি তালিকার লিংক খোলা যায়।
- স্বয়ংক্রিয় অনলাইন মূল্য আপডেট, সম্পূর্ণ অফলাইন ডেটাবেস, এবং সব ব্র্যান্ডের পূর্ণ তালিকা এখনো যুক্ত নয়।
- প্যাকেটের OCR লেখা বের করতে পারে; এটি নিজে থেকে ওষুধের পরিচয় নিশ্চিত করে না।
- মূল্য যাচাই না থাকলে প্রকৃত দোকানদারি দাম ধরে নেওয়া যাবে না। MRP/সরকারি তালিকাভুক্ত মূল্য এবং দোকানের বিক্রয়মূল্য আলাদা হতে পারে।
- অ্যাপ রোগ নির্ণয়, প্রেসক্রিপশন বা ডোজ পরামর্শের বিকল্প নয়।

## সরকারি রেফারেন্স
- DGDA ওষুধের তালিকা: https://adr.dgdagov.info/medicines
- DGHS registered drug registry: https://fhir.dghs.gov.bd/core/ValueSet-dgda-registered-drugs.html
- DGDA: https://dgda.gov.bd/

DGHS-এর প্রকাশিত গাইডে DGDA registry থেকে 39,196 finished pharmaceutical drug product concepts উল্লেখ আছে। এটি অ্যাপে সেই সব রেকর্ড অফলাইনে আছে—এমন দাবি নয়। পূর্ণ ডেটা ব্যবহার করার আগে ডাউনলোড/সিঙ্ক সুবিধা, লাইসেন্স ও পুনর্বিতরণের অনুমতি যাচাই করা প্রয়োজন।
